# Fixtures

Every audio file here is generated by `tools/make-fixtures.sh` (`npm run fixtures`, needs ffmpeg and ffprobe) from sine tones, noise, silence and clipped tones. They are original and rights-cleared. No commercial recordings. Output is deterministic: noise sources use fixed seeds and ffmpeg runs with `-fflags +bitexact -flags +bitexact -map_metadata -1`, so a rerun gives identical files (checked by hashing). All WAVs are 16-bit PCM.

## Oracle

Each `<name>.oracle.json` comes from ffmpeg's EBU R128 filter, run as

```
ffmpeg -nostats -i <name>.wav -af ebur128=peak=true -f null -
```

The script parses the `Summary:` block (`I:` integrated loudness in LUFS, `LRA:` loudness range in LU, `Peak:` true peak in dBTP). Sample rate, channels and duration come from `ffprobe`. Keys: `integratedLufs`, `loudnessRangeLu`, `truePeakDbtp`, `sampleRate`, `channels`, `durationSec`. The JavaScript meter must match these within 0.1 LU (T3).

## Files

| Name | Format | Content | Purpose |
|---|---|---|---|
| good | 48 kHz stereo, 8 s | A3, C4, E4 sines plus pink noise (seed 11), gained to -14 LUFS | Passing track |
| bad | 44.1 kHz stereo, 7.5 s | 2 s digital silence, 3.5 s quiet tones plus white noise (seed 22) gained to -26 LUFS before the burst, a 5 ms hard-clipped 1 kHz burst, then a hard cut to 2 s silence | Quiet (about -23 LUFS), clipped, long lead and tail silence |
| cut | 44.1 kHz stereo, 4 s | G3 and B3 sines, no fade, no silence | Ends mid-signal. Separate from `bad` because one file cannot both end in silence and end mid-signal |
| silence | 48 kHz stereo, 5 s | Digital zero | Silence handling |
| clipped | 48 kHz stereo, 3 s | 440 Hz sine multiplied by 40 and hard-clipped to +/-1.0 | Full-scale clipping |
| mono | 48 kHz mono, 6 s | E4 sine plus white noise (seed 33), -18 LUFS | Mono input |
| sr44 | 44.1 kHz stereo, 8 s | D major tones, brown noise (seed 44), tremolo, -16 LUFS | 44.1 kHz path |
| sr48 | 48 kHz stereo, 8 s | E minor tones panned apart, pink noise (seed 55), -12 LUFS | 48 kHz path, different content from good |
| sample | 24 kHz mono, 38 s | Demo track: 1.5 s silence, eight 4.25 s chords (C, Am, F, G, twice), 2.5 s silence, -19 LUFS | Preloaded track for the judged loop. Quiet on purpose so the loudness fix has work to do |

Mono and 24 kHz keep `sample.wav` near 1.8 MB. The whole folder is about 11 MB.

Gains to a target loudness are two-pass: the script renders the raw mix, measures it with `ebur128`, then applies `volume=<target - measured>dB`. The exact ffmpeg invocation for every file is in `tools/make-fixtures.sh`.

## Silence

For digital silence ffmpeg reports integrated loudness `-70.0 LUFS` (the absolute gate floor, because no block passes the gate), loudness range `0.0 LU` and true peak `-inf dBFS`. JSON cannot hold `-inf`, so `silence.oracle.json` stores `integratedLufs: -70` and `truePeakDbtp: null`. The meter must return -70 (the floor, never `-Infinity` or `NaN`) for loudness and `-Infinity` for true peak, and the UI shows "no signal".

## Clipping

`clipped.wav` and the burst in `bad.wav` reach 16-bit full scale. The oracle true peak is above 0 dBTP (about +0.2 and +0.6) because of inter-sample overshoot.

## Sample lyrics and cues

`sample.lyrics.txt` holds eight original placeholder lines written for this project. `sample.cues.json` is `{ "file", "lines": [{ "startMs", "text" }] }` with `startMs` strictly increasing and non-negative. Line n starts with chord n, at 1500 + 4250 n ms.
