# Product purpose
PlusG resurrects CD+G (1985), the dead disc format for timed lyric graphics, as a working release-readiness tool for independent musicians. Judged loop: **Measure** (score out of 100, five named categories, each with its measured number), **Fix** (safe, reversible fixes, re-measured and rescored), **Release** (a real `.cdg` packet stream, a retro preview decoded from that stream, a modern preview, HTML/PDF one-sheet, WebM clip).

- Everything runs in the browser and ships as static files.
- Lyric timing is tap-along. The sample ships with a finished cue file.
- Inspired by Vrenvo's public "Measure. Fix. Release." idea. Brand-new code. Never read, copy or import Vrenvo production code, models, keys or data.
- The retro view is an homage and a timing preview. Do not claim compatibility with every legacy player.
- A preloaded sample track must let a judge finish the whole loop without uploading.
- English UI and docs. Desktop-first; the judged path must work on a phone.
