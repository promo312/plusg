# UI tone
- Feels like a modern release disc and an A&R sheet: calm, intentional, complete.
- Not a Halloween costume. Not a marketing landing page. The tool is the first screen.
- Plain, specific copy. Each category shows a numeric mark, a one-line reason and the measured number.
- Retro preview: 300x216 grid, 16 colors, blocky type, drawn by decoding the `.cdg` stream. Modern preview: clean typography. Both driven by the same cue list.
- **No Compact Disc logo and no other third-party mark** anywhere in the UI, one-sheet, clip or screenshots. Draw any disc motif as plain original geometry.
- Phone checks on the judged path: tap targets >= 44px, no horizontal scroll.
